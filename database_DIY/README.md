# メモ
一般利用者が求人情報に応募すると、応募リストに追加される。
また、その時に、応募した求人情報の法人に対して、メッセージが送信される。
法人はそのメッセージを受領、もしくは拒否することができる。
受領した場合、一般利用者が求人に参加したとみなし、レビューを行うことができるようにする。
