\section{現状の課題}
高知県の若者の人口流出と高齢化の進行により、人口減少が深刻な状況である。
令和4年10月1日時点で
\begin{itemize}
    \item 生産年齢人口(15~64歳)	360,098人(割合:53.3\%)で過去最低
    \item 年少人口(15歳未満)~~~~~71,618人(割合:10.6\%)で過去最低
    \item 老齢人口(65歳以上)~~~~~243,994人(割合(高齢化率):36.1\%)で過去最高
\end{itemize}

\par
高齢化の波は祭りなどといった地域行事にまで及んでおり、
高知県が2019年から2021年度に行った``民族芸能緊急調査''によると、
市町村の協力で各地域の代表者にアンケートを配布し、
約900件の民俗芸能について回答を得た結果、現存する祭り行事は500件にとどまり、
385件は中断かすでに廃絶していることが判明している。アンケート結果として、
``地域に役回りを担当する子供がいない"という回答が多く、
これは県保護無形民俗文化財も6件含まれていた。\cite{bib:KouchiMinzoku}
\par
かつて``土佐は民族芸能の宝庫"と称されていた高知県であるが、
現在は多くの祭り行事が担い手不足により存続の危機となっており、
これは香美市も決して例外ではない。同資料によると、香美市の１２行事のうち、
人形芝居、相撲、太刀踊り、古踊の４件が中絶または廃絶しており、
\cite{bib:KouchiMinzoku}早急に若者と行事を繋げる手段を模索する必要がある。
\section{課題解決のための提案}
上記の課題より若者と行事を繋げる画期的な手段として、
我々ChaO!株式会社は気軽にスマートフォン上で利用することが出来る、
行事特化の地域密着型アルバイト求人アプリシステムを提案する。
\subsection{解決されると考えられる事象…行事やイベントの活性化}
現在(2023年10月)、
高知県香美市内の行事やイベントでの担い手不足や参加者減少の原因としては、
主催者側の高齢化や人口減少が考えられ、この行事やイベントを継続していくためには、
若者世代の参加者の増大が不可欠となっている。
\par
しかし、現状この地域の若者世代の行事やイベント参加率は減少している。
その原因は、若者世代への宣伝不足である。それは、
従来の宣伝方法である地域のスーパーや掲示板などに設置されている、
紙媒体の広告への注目度の減少が大きく関わっている。従って、
提案するシステムを導入することにより、
スマートフォン上でも容易に行事やイベントなど地域情報を取得することができ、
導入前よりも多くの人へ情報の伝達が可能となる。さらに、
これまで紙媒体の宣伝方法からシステム導入によって、アプリ上での宣伝方法となることで、
紙の印刷代、広告の設置料金を支払う必要がなくなり、このシステムへの月額料金のみで、
広告内容の変更が容易にでき、
風や雨などによって広告が傷つき内容が見えなくなる恐れをなくすことが可能となる。
\par
このように、システム導入により多くの人に行事やイベント情報が伝わり、
人員不足などの課題が解決することで、
行事やイベントの活気が戻ると考えられる。
