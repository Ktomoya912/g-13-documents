\section{現状の課題}
高知県の若者の人口流出と高齢化の進行により、人口減少が深刻な状況である。
令和4年10月1日時点で
\begin{itemize}
    \item 生産年齢人口(15~64歳)	360,098人(割合:53.3\%)で過去最低
    \item 年少人口(15歳未満)~~~~~71,618人(割合:10.6\%)で過去最低
    \item 老齢人口(65歳以上)~~~~~243,994人(割合(高齢化率):36.1\%)で過去最高
\end{itemize}

\cite{bib:NaikakuKourei}と比べ7.0\%も高く、全国順位は2位
\cite{bib:NaikakuChiki}であり、とても深刻な問題である。

\par
高齢化の波は祭りなどといった地域行事にまで及んでおり、
高知県が2019年から2021年度に行った``民族芸能緊急調査''によると、
市町村の協力で各地域の代表者にアンケートを配布し、
約900件の民俗芸能について回答を得た結果、現存する祭り行事は500件にとどまり、
385件は中断かすでに廃絶していることが判明している。アンケート結果として、
``地域に役回りを担当する子供がいない"という回答が多く、
これは県保護無形民俗文化財も6件含まれていた。\cite{bib:KouchiMinzoku}
\par
かつて``土佐は民族芸能の宝庫"と称されていた高知県であるが、
現在は多くの祭り行事が担い手不足により存続の危機となっており、
これは香美市も決して例外ではない。同資料によると、香美市の１２行事のうち、
人形芝居、相撲、太刀踊り、古踊の４件が中絶または廃絶しており、
\cite{bib:KouchiMinzoku}早急に若者と行事を繋げる手段を模索する必要がある。
\section{課題解決のための提案}
上記の課題より若者と行事を繋げる画期的な手段として、
我々ChaO!株式会社は気軽にスマートフォン上で利用することが出来る、
行事特化の地域密着型アルバイト求人アプリREEL(Region Event Excitement Linkup)を提案する。
\subsection{解決されると考えられる事象}
\subsubsection{行事やイベントの活性化}
インターネットやSNSの発達により娯楽の多様化した現代、行事に対して若者の興味を向けさせるのは難化の一途をたどっている。
だからといって広告により無理やり興味関心を持たせようとしてもあまり効果は期待できない。
% !ここに広告の影響度アンケートを挿入
そこで我々は、行事特化求人アプリを用いることによって、あくまで利用者に自主的に広告情報を取得させ、興味関心を持たせることができると考察する。
\par
そもそも行事関係者が求める求人条件は長期間ではなく、テント設営や警備員、会場スタッフなどの短期間、単発のアルバイトである。
この理由は、行事の行われる期間は短く、行事の行われている間のみの働き手を求めているためである。
また、短期間で単純作業の多い行事求人であるため、
多くの行事のアルバイトでは、通常行う必要のある面接などの学生にとって面倒な作業が省かれることが多い。
この求人条件は、手軽に短期間でお金を手に入れたい大学生などの若者にとって、とても合致した条件となっているのである
。そのため、若者は目当ての求人情報を取得するため、本システムを使用して自主的に行事の広告情報を見聞きし、行事に対して興味関心を高めていくと考えられる。
また、実際に行事で働くことによって、その行事に対して興味を持つことも考えられる。このようにして、利用者が受動的に広告情報を取得するため、
クーポン券やカードのポイントなどの特典を用いることなくシステムの利用を促すことができ、同時に広告効果を得ることのできるシステムが行事特化求人システムなのである。
\par
また、地域のスーパーや掲示板などでは宣伝目的のポスターや旗などが多く設置されているが、若者は紙などのアナログ媒体への興味は薄く、
スマホ広告やＳＮＳ上のインフルエンサーによる広告に対して興味関心を持っていることが多い。
% !ここにアンケートの結果を挿入
そこで、スマートフォン上で扱える本システムを用いることによって、若者に行事に対する興味関心を持たせるだけでなく、
アナログ媒体である紙の印刷や、広告の設置料金を節約することができ、
システムに対する月額料金のみで、広告内容の変更が容易に可能となり、
雨風による広告劣化の修繕や回収による費用の削減をすることが可能となるのである。
\par
このように、行事特化求人システム導入により多くの若者に行事やイベント情報が伝わり、担い手不足解消や、
若者の行事に対する興味関心の向上、宣伝費の節約によって、本システムが若者と行事の橋渡し役となり、
より地域行事に対して活気をもたらすことができると考える。
\subsubsection{民営事業の衰退問題}
現在、高知県香美市内の民営事業では行事やイベントと同様に、人口減少の影響を受け訪れるお客の減少、
後継者不足となり衰退の一途を辿っている状態となっている。この事態を改善するためには、若者世代のお客、
働き手の獲得が不可欠となるが、こちらも行事やイベントと同様、アナログ媒体での宣伝が主となっているため、
若者世代の獲得が困難となっている。そこで我々が提案するシステムを行事やイベントだけでなく、民営事業にも適応させていくことで、
より多くの人に民営事業の存在を認知してもらうことが可能となり、
同時に働き手の募集も可能となることから、民営事業の衰退を防ぐ起爆剤となり現状の課題を解決する手段となることができると考える。
\section{機能概要・前提条件・制約事項}
\subsection{機能概要}
\subsubsection{一般利用者向け機能}
以下に一般利用者向け機能を示す。
※ここで示す一般利用者とは求人応募者やイベント参加者などを指す。
\begin{itemize}
    \item 会員機能
          \begin{itemize}
              \item[-] 新規会員機能\\
                  一般利用者が名前、性別、歳、メールアドレス、パスワードを登録し会員になる機能。
                  また、新規会員登録の際に規約を提示し、規約に従う場合に新規登録を行う。
              \item[-] ログイン・ログアウト\\
                  ログイン機能では、すでに会員である一般利用者がメールアドレス、
                  パスワードを入力することによってアプリにログインをすることができる。
                  ログアウト機能では、アプリにログインしている会員が任意のタイミングでログアウトをすることができる。
              \item[-] 退会\\
                  会員が任意のタイミングでアプリ会員から退会することができる機能。会員情報を完全に削除する。
              \item[-] 会員情報確認\\
                  会員ごとに存在するマイページを確認する機能。会員情報として登録している情報が表示される。
              \item[-] 会員情報変更\\
                  登録している会員情報を変更する機能。
              \item[-] 履歴書情報記述機能\\
                  求人に応募する場合に用いる履歴書を記述する機能。
                  この機能は新規会員登録の場合にはスキップができ、後々記述することが可能とする。

          \end{itemize}
    \item メディア機能
          \begin{itemize}
              \item[-] 求人情報表示\\
                  香美市内にある求人情報を表示する。一覧画面では行事・イベント名、開催地、
                  労働内容、労働期間、時給(または日給)。を表示する。
                  また、一覧画面にて求人情報を気になるリストへと入れることができるようにする。
                  また、詳細画面では行事・イベント名、開催地(マップ表示)、労働内容、労働期間、
                  時給(または日給)、行事・イベント情報(公式サイト、SNSなどのリンク)、気になるリスト数、
                  レビュー評価、求人募集者が変更した詳細画面を表示する。
                  詳細画面ではこれらの表示に加えて気になるリスト入れるまたは外す動作と、求人の評価を行うことができるようにする。
                  一覧に表示する順序は通常は開催時期が近い順であり、変更可能とする。
              \item[-] 行事・イベント情報表示\\
                  香美市内で行われるイベント情報を表示する。一覧画面では行事・イベント名、開催地、開催期間を表示する。
                  また、一覧画面にて行事・イベント情報を気になるリストへと入れることができるようにする。
                  また、詳細画面では行事・イベント名、開催地(マップ表示)、開催期間、行事・イベント開催者が変更した詳細画面を表示する。
                  詳細画面ではこれらの表示に加えて気になるリスト入れるまたは外す動作と、行事・イベントの評価を行うことができるようにする。
                  一覧に表示する順序は通常は開催時期が近い順であり、変更可能とする。
                  一覧表示画面では開催時期がすでに終了したものに対しては表示を行わない。
              \item[-] 表示順変更機能\\
                  一覧画面にて求人情報、行事・イベント情報を表示する順序を開催時期、
                  気になるリスト数、レビュー評価、レビュー数順に変更可能とする機能。
                  この表示順変更機能は検索時にも有効とする。
              \item[-] 気になるリスト機能\\
                  気になる求人や行事・イベントを気になるリストへと入れることができる機能。
                  入れる方法は一覧または詳細画面にて行う。気になるリストの確認はマイページで行うことが可能であり、気になるリストに入っている行事・イベントが近づくと通知を行う。
              \item[-] レビュー評価機能\\
              \item[-] タグ分け機能\\
                  一覧表示の際、求人情報と行事・イベント情報を分けてみることができるようにする
                  (通常設定)。これに加え、求人情報表示の場合は開催時期、時給(日給)、労働時間、
                  気になるリスト数、レビュー評価によりタグ分けが可能であり、行事・イベント情報では
                  開催時期、気になるリスト数、レビュー評価、レビュー数によりタグ分けが可能とする。
                  このタグ分け機能は検索時と閲覧履歴にも有効とする。
              \item[-] 求人・行事・イベント検索機能\\
                  求人・行事・イベントを検索する機能。検索時にタグによって表示内容を選択可能とする。
                  また、開催時期が過ぎた求人・行事・イベントに関しては表示を行い、一覧画面では開催時期が過ぎたことを表示し、灰色で示す。
              \item[-] 閲覧履歴機能\\
                  一般利用者が詳細を開いた求人・行事・イベントの履歴を取得しておき、
                  マイべージにて閲覧することができる機能。
                  閲覧履歴ページにて情報を選択すると詳細ページへと進むことができる。
                  開催時期が過ぎた求人・行事・イベントに関しては開催時期が過ぎたことを表示し、灰色で示す。
          \end{itemize}
\end{itemize}
